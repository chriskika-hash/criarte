🎨 Visão Geral
O projeto foi desenhado com um conceito Dark Luxury/Creative, utilizando paleta de cores contrastantes (tons de azul-escuro profundos #070913 e detalhes em coral/dourado #FF6B5B), fontes elegantes (Cinzel e Montserrat) e componentes modernos.

Seções do Site:
Hero / Banner Principal: Apresentação da marca com arte abstrata 3D e botão de chamada para ação (CTA).

Serviços: Grade interativa listando as principais soluções oferecidas.

Portfólio: Galeria de projetos em destaque com efeito hover e indicadores de navegação.

Sobre: Seção institucional com a história e propósito da agência.

Rodapé: Links rápidos de navegação, contactos, redes sociais e assinatura estilizada.

✨ Funcionalidades
Design 100% Responsivo: Adaptado para telemóveis, tablets e monitores de alta resolução.

Animações e Efeitos CSS: Transições suaves ao passar o cursor (hover) nos cartões de serviços e portfólio.

Tipografia Web Google Fonts: Combinação de fontes serifadas elegantes e sans-serif limpas.

Ícones Vetoriais: Integração com FontAwesome 6 para ícones leves e escaláveis.

🛠️ Tecnologias Utilizadas
HTML5: Estruturação semântica do conteúdo.

CSS3: Estilização, variáveis CSS, Flexbox e CSS Grid.

Google Fonts: Importação das fontes Cinzel, Montserrat e Reenie Beanie.

FontAwesome: Biblioteca de ícones sociais e de serviços.

🚀 Como Executar
Por ser um projeto web estático, não é necessária a instalação de dependências ou servidores complexos.

Clonar o repositório:

Bash

git clone https://github.com/teu-usuario/criarte-landing-page.git
Navegar até a pasta do projeto:

Bash

cd criarte-landing-page
Abrir no navegador:

Basta dar um duplo clique no ficheiro index.html ou abri-lo usando extensões como o Live Server no VS Code.

✏️ Personalização
Para adaptar o site à tua própria agência ou cliente:

Cores: Altera as variáveis CSS no início da tag <style> dentro de index.html:

CSS

:root {
    --bg-dark: #070913;
    --accent-coral: #ff6b5b;
    --text-light: #ffffff;
}
Imagens: Substitui os links das imagens dentro da secção #portfolio e #sobre pelas tuas próprias fotos ou artes em alta resolução.
